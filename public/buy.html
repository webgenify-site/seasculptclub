Good to know

Using your code.

How do I book with my code?

After checkout we email you a class code. When you’re ready, go to Classes, add a class to your cart and enter the code at checkout. Your spot is covered and you’ll get a booking confirmation.

Can I use my code for Santa Sculpt and other special events?

Yes. Each class on a code is a $35 value. Special events that cost more, like Santa Sculpt, just need the difference paid at checkout (for example, $10 for a $45 event).

Do class packs expire? Can I share them?

Class packs never expire, and you can use your code to book friends too. The new member deal is for one person, and its extra class expires 21 days after purchase.
